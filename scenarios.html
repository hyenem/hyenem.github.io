사용 시나리오

실제 사용자가 BudsAI를 어떻게 활용하는지 구체적인 예시들. 흐름을 애니메이션으로 보려면 시뮬레이션으로.

목차
  • 대표 시나리오
  • 의도(Intent) 분류
  • 확장 시나리오

대표 시나리오

청취 중이던 것 트리거 후 사용자 음성 AI 응답
카페에서 흘러나오는 음악 "이 노래 누구 곡이야?" "아이유의 'Love wins all'입니다"
영어 팟캐스트 "방금 quintessential 무슨 뜻?" "전형적인, 본질적인이란 뜻이에요"
미국 드라마 시청 "방금 대사 한국어로 번역해줘" "'그가 그럴 줄 알았어'라는 뜻이에요"
회의 통화 "방금 김 부장님이 뭐라고 했어?" "다음 주 화요일까지 보고서 달라고 하셨어요"
강의 청취 "방금 설명한 엔트로피 다시 쉽게 풀어줘" "엔트로피는 쉽게 말해 무질서도인데..."
라디오 뉴스 "이 사건 배경이 뭐야?" "말씀하신 사건은 어제 발생한..." (Track A STT + 외부 검색)
음악 듣는 중 "이 가수 다른 노래 추천해줘" (곡 식별 → 같은 아티스트 추천)

의도(Intent) 분류

Track B(사용자 질문)를 STT로 변환 후 의도를 분류하여 Track A(직전 사운드)에 적절한 처리를 적용합니다.

🎵 song_id

"이 노래 뭐야?" → 음악 fingerprint 매칭으로 곡 정보 반환.

▶ 라이브 데모 열기 →

📝 transcribe

"방금 뭐라고 했어?" → Track A STT → 텍스트 그대로 반환.

📋 summarize

"지금 한 말 요약해줘" → STT → LLM 요약.

📖 define

"이 단어 무슨 뜻?" → STT → 단어 추출 → 사전 검색.

🌐 translate

"한국어로 번역해줘" → STT → 번역 모델.

🐦 classify

"이거 새 소리야?" → 환경음 분류 모델.

🔍 search

"이 사건 배경 알려줘" → STT → 외부 검색 + LLM.

💡 recommend

"비슷한 거 추천해줘" → 곡 식별 → 추천 시스템.

확장 시나리오

연속 대화

사용자: (음악 듣는 중 트리거) "이 노래 뭐야?"

AI: "아이유의 'Love wins all'입니다."

사용자: (다시 트리거) "이 가수 다른 노래 추천해줘"

AI: "아이유의 다른 곡으로는 'Blueming', 'Celebrity'..."

→ PrevSessionID 메타데이터로 세션 컨텍스트 유지

오프라인 fallback

폰 인터넷 미연결 시 큐잉 후 연결되면 일괄 처리.

"인터넷 연결되면 다시 알려드릴게요"

긴 컨텍스트가 필요한 경우

강의/팟캐스트처럼 30초보다 긴 컨텍스트가 필요할 때 사용자가 버퍼 길이를 1분/3분으로 설정 가능.

단, 배터리 소비와 트레이드오프

→ 이 시나리오들이 어떻게 데이터로 표현되는지는 패킷 포맷에서, 서버가 의도를 어떻게 처리하는지는 서버 API에서 다룹니다.
