기술 부록 (비전공자 + 전공자용)

오디오 캡처 / 무선 통신 / 보안 / 패킷 / AI — 비전공자 한 페이지 요약 + 카테고리별 deep dive.

→ 부록 열기

핵심 아이디어

버즈가 출력 중인 오디오의 직전 N초를 링버퍼에 보관하다가, 사용자가 트리거 제스처를 입력하고 음성으로 질문하면, 두 오디오(직전 사운드 + 질문)를 함께 서버 AI로 보내 의도에 맞는 답을 TTS로 들려주는 구조입니다.

1. 상시 버퍼링

버즈 출력 사운드를 Opus로 인코딩해 압축 링버퍼에 유지. 약 150KB로 30초 보관.

2. 제스처 트리거

버즈 터치패드 롱프레스로 트리거 → ARMED 효과음 → 마이크 ON.

3. 음성 질의

사용자가 자연어로 질문하면 VAD가 침묵 감지 시 자동으로 녹음 종료.

4. AI 분석

서버가 (직전 오디오 + 질문) 컨텍스트로 의도 파악 후 적절한 답변 생성.

전체 아키텍처 한눈에

[Buds] ──BT(PAN)──> [Host: 폰/노트북/MP3/TV/eSIM] ──IP──> [Server + AI] ↑ │ └──────────────── TTS 응답 음성 ←─────────────────────────┘

버즈가 패킷 생성, mTLS 종단, HTTPS 요청까지 직접 수행합니다. 호스트(폰·노트북·MP3 등)는 표준 BT PAN으로 IP 라우터 역할만 — 페이로드는 못 봅니다. 앱 설치 없이도 OS 빌트인 BT 테더링만으로 동작합니다.
